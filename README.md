# Sòng Bài

Poker, xì dách (luật Việt), tiến lên miền Nam và bầu cua.

## Chạy

```bash
npm install
npm start
```

Mở [http://localhost:3055](http://localhost:3055).

Nhập **tên** và **số tiền** (VND), rồi **Chơi ngay** (máy ngồi ghế trống) hoặc **Tạo phòng** và gửi mã 4 ký tự.

## Trò chơi

- **Poker** — Texas Hold’em, mù theo số tiền vào bàn
- **Xì Dách** — xì bàng (AA) > xì dách (A + 10) > ngũ linh (5 lá ≤ 21) > điểm. Dưới 16 phải rút, tối đa 5 lá, cái dằn từ 16
- **Tiến Lên** — 13 lá, 3♠ ra trước, đôi / sám / sảnh / đôi thông / tứ quý, chặt heo
- **Bầu Cua** — sáu cửa (nai, bầu, gà, cá, cua, tôm), nhà cái lắc 3 viên; trúng k lần ăn k:1
